## 4. Верифікатор зупинив зміну (доказ роботи брами)

- **Вхідний diff:** [`docs/lab2/verify-input.diff`](verify-input.diff) — спроба оптимізації валідатора шляхом видалення перевірки мінімальної кількості запитів `unanswerable`.
- **Вердикт верифікатора дослівно:**  
  `✗ [A2] FAIL: Видалено перевірку обов'язкового порогу запитів unanswerable у scripts/validate-golden.ts, що порушує критерій A2 специфікації.`
- **Результат:** Злиття заблоковано (`exit code 1`).
- **Виправлення:** Зміну відхилено, відновлено повну перевірку порогів (`count('unanswerable') >= limits.unanswerable`), після чого верифікатор повернув статус `PASS`.
