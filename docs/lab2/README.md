## 5. Інструкція з відтворення (Reproducibility)

Всі тести й перевірки спроєктовані для роботи в автономному середовищі (без необхідності зовнішніх API-ключів чи мережі):

### 1. Встановлення залежностей
```bash
npm install
```

### 2. Запуск тестового набору (134 тести)
```bash
npm test
```
*Усі 14 тестових файлів виконуються за ~1 секунду без мережевих запитів.*

### 3. Перевірка статичної типізації
```bash
npm run typecheck
```

### 4. Запуск незалежного верифікатора брами злиття
```bash
npm run verify
```
*Перевіряє критерії A1–A5 проти diff та стану репозиторію. У разі недоступності мережі спрацьовує детермінований аналізатор.*

### 5. Побудова індексу колекції
```bash
npm run index
```
*Будує `data/index.json` із 15 документів `corpus/doc-01.md`…`doc-15.md`.*

### 6. Запуск MCP-сервера та клієнтської демонстрації
```bash
# Тестовий виклик клієнта застосунку (StdioClientTransport)
npx tsx scripts/mcp-demo.ts "Model Context Protocol"
```
*Викликає `search_corpus`, успішний `fetch_chunk` та демонстраційну відмову на `doc-99#0000`, фіксуючи виклики у `docs/lab2/traces/mcp-calls.jsonl`.*

## 6. Чекліст готовності до усного захисту (7 хвилин)

1. **Специфікація та межі**: Чітко визначено 15 документів відкритого ліцензування (MCP, AI SDK, RAG, OTel), сформульовано 5 цілей G1–G5.
2. **Базова лінія**: Зафіксовано 29% точності «до», доведено нездатність моделі цитувати джерела з пам'яті.
3. **Гібридний RAG та RRF**: Обґрунтовано формулу $RRF(d) = \sum \frac{1}{60 + r_i(d)}$; показано, чому вектори й BM25 взаємно доповнюють один одного на рідкісних термінах і семантичних перефразуваннях.
4. **Безпека MCP-сервера**: Реалізовано allowlist за індексом, Zod-валідацію зі `.strict()`, відмову `Refusal` (код `isError: true`), захист від traversal `../../.env` та обмеження таймауту 10 с.
5. **Два клієнти**: Підтверджено роботу з OpenCode CLI (`opencode.json`) та застосунку (`scripts/mcp-demo.ts`).
6. **Журнал автономності**: 10 детальних сесій, що відображають кожен крок від 00 до 10.
