## 6. Межі вимірювання
- Розмір вибірки $n = 17$ відповідних запитів дає похибку $\pm 15$ процентних пунктів при 95% довірчому інтервалі, що є типовим для невеликих експертних наборів курсу.
- Метрики recall@k та MRR оцінюють виключно якість вибірки фрагментів пошуковою системою, тоді як оцінка відповідей моделі враховує здатність LLM синтезувати факти без галюцинацій.
