# Таблиця переносності — Лабораторна 1

Порівняння конфігурацій, механізмів та поведінки для обраної пари агентів кодування: **OpenCode** та **GitHub Copilot CLI**.

| Критерій / Механізм | OpenCode | GitHub Copilot CLI | Коментар щодо переносності |
|---|---|---|---|
| **Файл правил (статичний контекст)** | Читає `AGENTS.md` у корені. | Читає `AGENTS.md`, `CLAUDE.md`, `.github/copilot-instructions.md`. | Повна переносність: спільний `AGENTS.md` успішно підхоплюється обома агентами без дублювання. |
| **Журнал дій (Hooks/Plugins)** | Плагін `.opencode/plugins/agent-log.js` (подія `tool.execute.after`). | Конфіг `.github/hooks/agent-log.json` (`postToolUse`) + `scripts/agent-log-hook.mjs`. | Формат вихідного файлу уніфіковано до JSONL (6 полів). Формати вхідних подій різні (camelCase проти об'єктів плагіна). |
| **Режим планування (Plan Mode)** | Агент Plan (перемикання через `Tab`). | Режим `/plan` у CLI. | Обидва інструменти підтримують розділення планування та виконання змін. |
| **Навички (Skills)** | Читає з `.claude/skills/` або `.agents/skills/`. | Читає з `.claude/skills/` або `.github/skills/`. | Синхронізація через `npm run sync-skills` забезпечує роботу однакових навичок в обох середовищах. |
| **Заборони доступу (Permissions/Deny)** | Налаштування дозволів в `opencode.json` або блокування в плагіні. | Скрипт перевірки аргументів інструменту в hook (вихідний код заборони). | Обидва дозволяють блокувати доступ до `.env*` файлів та деструктивних команд. |
| **Підключення MCP** | Секція `mcp` у конфігурації `opencode.json`. | Налаштування MCP через `~/.copilot/mcp-config.json` або проєктний конфіг. | Протокол MCP спільний, але формат реєстрації серверів відрізняється між інструментами. |
