# Таблиця переносності — Лабораторна 1

Порівняння конфігурацій, механізмів та поведінки для обраної пари агентів кодування: **OpenCode** та **GitHub Copilot CLI**.

| Критерій / Механізм | OpenCode | GitHub Copilot CLI | Коментар щодо переносності |
|---|---|---|---|
| **Файл правил (статичний контекст)** | Читає `AGENTS.md` у корені. | Читає `AGENTS.md`, `CLAUDE.md`, `.github/copilot-instructions.md`. | **Повна переносність:** спільний `AGENTS.md` успішно підхоплюється обома агентами без дублювання правил. |
| **Журнал дій (Hooks/Plugins)** | Плагін `.opencode/plugins/agent-log.js` (подія `tool.execute.after`). | Конфіг `.github/hooks/agent-log.json` (`postToolUse`) + `scripts/agent-log-hook.mjs`. | **Потрібна адаптація:** формат вихідного журналу уніфіковано до JSONL (6 полів). Вхідні події різні (об'єкти плагіна проти camelCase arguments у Copilot). |
| **Режим планування (Plan Mode)** | Агент Plan (перемикання клавішею `Tab`). | Режим `/plan` у CLI. | **Повна переносність:** обидва інструменти підтримують розділення фази дослідження коду та внесення змін без запуску небажаних команд. |
| **Навички (Skills)** | Читає з `.claude/skills/` або `.agents/skills/`. | Читає з `.claude/skills/` або `.agents/skills/`. | **Повна переносність:** завдяки `npm run sync-skills` навичка `add-api-route` синхронізована в обох розташуваннях і автоматично розпізнається обома агентами. |
| **Заборони доступу (Permissions/Deny)** | Налаштування `"permission"` в `opencode.json` + плагін `.opencode/plugins/guard-env.js`. | Pre-tool hook у `.github/hooks/guard-env.json` + `scripts/guard-env.mjs`. | **Потрібна адаптація:** OpenCode використовує комбінацію масок файлів та runtime плагіна, тоді як Copilot CLI використовує перехоплення команд через скрипт `guard-env.mjs`. Обидва генерують рядок `denied`. |
| **Підключення MCP** | Секція `"mcp"` в `opencode.json` (віддалений транспорт HTTP). | Конфігурація MCP через `~/.copilot/mcp-config.json` або сесійна команда `/mcp add`. | **Потрібна адаптація:** формат протоколу MCP спільний, проте синтаксис конфігураційних файлів вендоро-залежний. |
| **Скріншот-тест (Browser E2E)** | Відкриває сторінку, валідує елемент через Chromium, зберігає `home-health-link.png`. | Відкриває сторінку, валідує елемент через Chromium, зберігає `home-health-link.png`. | **Повна переносність:** Playwright E2E тести запускаються однаково через npm-скрипт `npm run e2e` незалежно від агента. |
