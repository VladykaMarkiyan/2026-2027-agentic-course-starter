# Рішення про заміну моделі — Лабораторна 1

## 1. Контекст і обґрунтування заміни
- **Початкова модель:** `qwen3.5:4b` (типове налаштування для локального профілю `local` у `src/models.ts`).
- **Модель після заміни:** `qwen3:4b` (щільна модель на базі архітектури Qwen 3).
- **Причина заміни:** Модель `qwen3.5:4b` є гібридною (Mixture-of-Experts/hybrid context reuse). Під час тестування багатоетапних діалогів та викликів інструментів в Ollama (станом на вересень 2026) виявлено, що гібридна модель не гарантує повторного використання префікса контексту, через що поле `cache_read_input_tokens` залишалося рівним 0 на повторних кроках циклу. Щільна модель `qwen3:4b` (2.5 ГБ) має повноцінну детерміновану підтримку повторного використання KV-кешу префікса та стабільне формування викликів функцій.

## 3. Зміна конфігурації в репозиторії
У файлі `.env.local` зафіксовано явну модель:
```env
OLLAMA_MODEL=qwen3:4b
```
У коді `src/models.ts` профіль `local` динамічно підтягує значення змінної `OLLAMA_MODEL`.

## 4. Оцінка ризиків
- **Дата зняття з підтримки (retiresNotBefore):** Локальні ваги завантажені на диск робочої станції, тому модель не залежить від відключення API вендором і гарантовано функціонуватиме під час захисту.
- **Політика даних:** Повна конфіденційність: локальна модель не надсилає жодних телеметричних даних або фрагментів коду в зовнішню мережу.
- **Обмеження заліза:** Модель займає 2.5 ГБ VRAM/RAM, що безпечно вміщується в пам'ять більшості ноутбуків та не спричиняє Out-Of-Memory (OOM) помилок під час виконання юніт-тестів.
