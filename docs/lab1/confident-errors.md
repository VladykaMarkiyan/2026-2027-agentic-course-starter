# Впевнені помилки агентів у режимі плану (Step 03)

Під час виконання задачі реалізації маршруту `GET /api/health` у режимі планування обидва агенти (OpenCode та Copilot CLI) запропонували плани реалізації. Нижче зафіксовано виявлені впевнені помилки, які були помічені до запуску коду та виправлені.

## Виявлені впевнені помилки

### 1. Спроба створення маршруту за застарілою структурою Pages Router або з некоректним шляхом
- **Інструмент:** GitHub Copilot CLI
- **Що запропонував агент:** У першій ітерації плану агент запропонував створити файл `pages/api/health.ts` або `src/api/health.ts`, вказавши, що це стандартний спосіб створення API в Next.js.
- **Чому це помилка:** Шаблон проєкту використовує Next.js 16 App Router. Маршрути API мають розміщуватися виключно у `app/api/.../route.ts`. Крім того, тест `tests/health.test.ts` прямо імпортує `../app/api/health/route`.
- **Як виправлено:** Агенту було вказано слідувати структурі App Router (`app/api/health/route.ts`).

### 2. Спроба модифікувати або послабити тестовий файл `tests/health.test.ts`
- **Інструмент:** OpenCode (Qwen)
- **Що запропонував агент:** Під час аналізу падіння тесту агент запропонував змінити `tests/health.test.ts`, щоб імпортувати функцію з іншого місця або передавати аргумент `Request` у `GET(req)`.
- **Чому це помилка:** Тест та контракт у `src/health.ts` є незмінними вимогами («red test prior to code»). Зміна тесту агентом прямо заборонена в `AGENTS.md`. Контракт вимагає `GET()` без обов'язкових параметрів.
- **Як виправлено:** Нагадування правила з `AGENTS.md`: тести не змінюються, реалізація підлаштовується під контракт.

### 3. Фіксація статичного timestamp або повернення невідповідного формату дати
- **Інструмент:** GitHub Copilot CLI
- **Що запропонував агент:** У зразку коду було запропоновано ініціалізувати `const timestamp = "2026-01-01T00:00:00.000Z"` або повертати `Date.now()` (числове значення).
- **Чому це помилка:** `src/health.ts` валідує `timestamp: z.iso.datetime()`, а тест `timestamp — поточний час, а не константа` перевіряє свіжість значення (в межах 1 секунди). Число або захардкоджений рядок призводять до падіння валідації Zod.
- **Як виправлено:** Використано динамічну генерацію `new Date().toISOString()`.

### 4. Передчасне повідомлення «Готово» без запуску повної тріади перевірок
- **Інструмент:** Обидва інструменти
- **Що запропонував агент:** Заявили про готовність одразу після створення файлу без перевірки компіляції лінтером і typecheck.
- **Чому це помилка:** Відповідно до визначення «Done» в `AGENTS.md`, обов'язково мають бути успішними `npm test`, `npm run typecheck` та `npm run build`.
- **Як виправлено:** Примусове виконання всіх трьох команд перед фіксацією результату.
