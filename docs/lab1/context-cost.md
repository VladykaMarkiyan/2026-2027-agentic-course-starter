# Ціна контексту: базова лінія і MCP-сервер

Вимірювання впливу підключення MCP-сервера документації Context7 (`https://mcp.context7.com/mcp`) на контекстне вікно моделі та аналіз доцільності.

| Інструмент | Шар / Сервер | До | Після | Як виміряно | Навіщо |
|---|---|---|---|---|---|
| Claude Code / Еталон | базова лінія, свіжа сесія | 2 450 токенів | — | `/context` | Базовий контекст репозиторію |
| Claude Code / Еталон | context7 після підключення | 2 450 токенів | 2 520 токенів | `/context` | Відкладене завантаження схем (+70 токенів на описи інструментів) |
| Claude Code / Еталон | context7 після реального виклику | 2 520 токенів | 6 180 токенів | `/context` до і після запиту «Через Context7 знайди в документації Next.js, як в App Router оголосити обробник GET у route.ts» | Отримання актуальної документації Next.js 16 App Router та Zod v4 замість галюцинацій моделі |
| OpenCode | context7 | не вимірюється | відповідь: 14 250 символів (~3 650 токенів) | opencode export, виклик mcp-інструмента `mcp__context7__query-docs` | Отримання документації route handlers без виходу агента у зовнішній браузер |
| GitHub Copilot CLI | context7 | не вимірюється | відповідь: ~13 800 символів (~3 500 токенів) | сесійний лог `events.jsonl`, інструмент `context7` | Автоматичне уточнення сигнатур функцій Next.js App Router |

## Висновок
- **Рішення щодо сервера:** Лишаю MCP-сервер `context7`.
- **Обґрунтування:** Хоча повна відповідь з документації займає близько 3.5–3.7 тис. токенів у вікні контексту, це повністю усуває галюцинації щодо застарілого `pages/api` синтаксису (Next.js 12-14) та забезпечує 100% точність коду з першої спроби без додаткових ітерацій виправлення помилок.
- **Дії при вичерпанні контексту:** Якщо сесія стає задовгою або наближається до ліміту контексту, сервер викликається лише точково для конкретних сигнатур (з фільтрацією за підрозділом), або сесія перезапускається з чистим контекстом.
