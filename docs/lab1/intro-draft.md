# Чернетка «Вступу» курсової роботи

**Тема:** Інженерія автономних агентних систем для безпечної розробки та підтримки програмного забезпечення.

## 1. Актуальність теми
Швидкий розвиток великих мовних моделей (LLM) трансформував парадигму розробки програмного забезпечення від простих асистентів генерації коду до автономних агентних систем, здатних самостійно планувати, досліджувати кодову базу, виконувати команди та верифікувати результати. Проте надання агенту доступу до терміналу та файлової системи несе критичні ризики: галюцинації щодо структури проєкту, випадкове видалення або перезапис файлів, неконтрольоване зациклення з вичерпанням лімітів API та витік конфіденційних ключів середовища. 

Тому створення агентно-готових репозиторіїв та детермінованих агентних циклів з чіткими межами довіри, обов'язковими доказами правильності дій та прозорим обліком витрат є нагальною інженерною проблемою.

## 2. Мета і завдання роботи
Метою курсової роботи є розробка архітектури та реалізація програмного комплексу автономного кодуючого агента з багаторівневою системою захисту та оцінки вартості.

Для досягнення мети вирішуються такі завдання:
1. Дослідження та проєктування механізму драбини довіри (рівні L0–L5) з автоматичною ізоляцією деструктивних дій до моменту явного підтвердження оператором.
2. Реалізація власного мінімалістичного агентного циклу з підтримкою різних протоколів API (Messages, Chat Completions) та гарантованою зупинкою за лімітом кроків або бюджетом токенів.
3. Побудова системи автоматизованого аудиту дій агента на основі структурованих JSONL-журналів та інтеграція телеметрії трасування (OpenTelemetry/Langfuse).
4. Порівняльний аналіз ефективності використання контексту, кешування префіксів та вартості роботи агентів на хмарних і локальних моделях.

## 3. Об'єкт і предмет дослідження
- **Об'єкт дослідження:** процеси взаємодії автономних програмних агентів з кодовою базою та інструментами середовища виконання.
- **Предмет дослідження:** методи обмеження прав доступу, валідації дій за допомогою автоматичних тестів, структурування відповідей за схемами Zod та оптимізації витрат токенів.

## 4. Очікувані результати
Створення практичного агентного фреймворку, що дозволяє безпечно делегувати рутинні завдання супроводу коду (додавання ендпоінтів, перевірка відповідності контрактам, рефакторинг) без ризику компрометації секретів чи порушення цілісності проєкту.
