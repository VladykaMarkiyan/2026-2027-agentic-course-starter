# AGENTS.md

Навчальний Next.js (App Router) репозиторій курсу «Агентна інженерія».

## Межі та безпека
- `.env` та `.env.local` не читати і не редагувати: секрети веде виключно людина.
- `.agent-log/` не змінювати і не очищати: це незмінний журнал дій для аудиту.
- `package.json` та `package-lock.json` змінювати лише за прямою вказівкою людини.
- Дії `git push`, створення тегів або видалення файлів вимагають підтвердження.

## Домовленості
- Моделі обирати через ролі з `src/models.ts`.
- Створювати ендпоінти в структурі Next.js App Router: `app/api/<route>/route.ts`.
