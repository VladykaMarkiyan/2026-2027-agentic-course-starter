# AGENTS.md

Навчальний Next.js (App Router) репозиторій курсу «Агентна інженерія» для перевірки агентного циклу та контрактів.

## Перш ніж звітувати «готово»
- Запусти `npm run typecheck`, `npm run lint` та `npm test`.
- Усі три перевірки мають завершитися успішно (код 0); покажи фінальний вивід команд.

## Межі та безпека
- `.env` та `.env.local` не читати і не редагувати: секрети веде виключно людина.
- `.agent-log/` не змінювати і не очищати: це незмінний журнал дій для аудиту.
- `package.json` та `package-lock.json` змінювати лише за прямою вказівкою людини.
- Дії `git push`, створення тегів або видалення файлів вимагають підтвердження.
- Тести у `tests/` мають бути детермінованими: не звертатися до зовнішньої мережі і платних API.

## Домовленості
- Моделі обирати через ролі з `src/models.ts` (наприклад, `MODELS.cheap`), а не жорстко закодованими рядками.
- Якщо тест червоний, поясни причину падіння перед зміною коду; заборонено послаблювати перевірки в тестах.
- Створювати ендпоінти в структурі Next.js App Router: `app/api/<route>/route.ts`.
- Формат повідомлень комітів: Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`).
